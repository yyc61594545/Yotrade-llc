## 二、Pro vs Max 5x vs Max 20x 决策矩阵

这是本文的核心。三档之间的价差是 **5 倍与 10 倍**，但用量差是 **5 倍与 20 倍**——单位成本随档位递减。问题在于你是否真的能用满。

| 你的画像 | 推荐套餐 | 月成本 | 关键判断点 |
|---|---|---|---|
| 每天 1-2 段对话，做写作 / 翻译 | Pro | $20 | 5 小时 40 条基本触不到限 |
| 每天用 Claude Code 写代码 2-4 小时 | Pro | $20 | 单文件重构够用，但要留意大改会撞墙 |
| 每天 Claude Code 8 小时 + 长上下文 | Max 5x | $100 | Pro 会在 90 分钟内触发冷却 |
| 全职 AI 工程师 / Agent 循环调用 | Max 20x | $200 | 只有 Max 20x 撑得住 10+ 小时无间断 |
| 团队 5-20 人共享 | Team Standard | $25×N | 数据隔离 + Admin 后台，最少 5 座 |
| 团队 5-20 人重度用 Claude Code | Team Premium | $125×N | 相当于每人独享 Max 5x |
| "拼车" / 淘宝二手号 | ❌ 不推荐 | 看似省 60% | 2026 年 5 月起主动封号，2-3 周即失效 |

✅ **推荐做法**：

1. **先 Pro 用 30 天**。90% 的用户能在 Pro 上完成日常写作、翻译、代码 review。
2. **看每周撞限次数**。5 小时窗口触发 "You've reached your usage limit" 每周 ≥ 3 次 → 升 Max 5x。
3. **Max 20x 的门槛在使用时长而不是任务复杂度**。同一个复杂任务，Pro 也能跑，只是要分 3-4 个 5 小时窗口。真正需要 Max 20x 的场景是**连续 8+ 小时的 Agent 长循环 / 大型代码库整体重构 / 全天开着 Claude Code 让它自己迭代**。

⚠️ **常见误判**：把 Max 20x 当成"模型更强"来买。**Max 5x 与 Max 20x 用的模型是同一批**（Opus + Sonnet），差别只在窗口内可触发的调用次数上限。你花 $200 不会拿到"更聪明的 Claude"，只是拿到"更多次一样聪明的 Claude"。

## 六、常见风控与封号规避

### 6.1 Stripe 的 4 大触发点

Anthropic 后端用的 Stripe 反欺诈规则库，我们在真实订单里观察到以下 4 类会 100% 触发风控：

⚠️ **地理跳变**：浏览时用美 IP、支付瞬间被检测到中国 IP → 立刻拒付。**支付全程不能切网络**。

⚠️ **BIN 段黑名单**：Stripe 内部维护高风险 BIN 列表，绝大多数常见虚拟卡 BIN 在名单里。

⚠️ **短时多次尝试**：同一账户 24 小时内 3 次以上支付失败 → 账户被标记为 `high_risk`，即使后续换真实美卡也可能被拒。

⚠️ **账单地址与卡不符**：账单地址填了大陆地址但用香港卡 → 立刻拒付。**账单地址必须与卡的发卡地严格一致**。

### 6.2 账号封停的 3 大主动行为

Anthropic 2026 年在《Usage Policies》里明确了 3 类会导致**主动封号**（不只是拒付）的行为：

- 🚫 **多人共用同一账户**：短时间内 IP 反复跳国家（例如 5 小时内 中国 → 香港 → 美国 → 日本），账户被封 24 小时到永久不等。
- 🚫 **短时批量退款**：拿虚拟卡订阅后立刻申请退款 → 账户与卡 BIN 双双入黑名单。
- 🚫 **绕过速率限制**：用脚本模拟并发或第三方代理堆叠 5 小时窗口配额 → 账户直接封停，不解封。

✅ **推荐做法**：

1. 一个 Claude 账户绑定**一个稳定 IP 地区**，最好用固定住宅代理，不要 VPN 跳国家。
2. 支付卡与账单地址属地一致（美卡 → 美国地址，港卡 → 香港地址）。
3. 订阅升档 / 降档在**账户设置里操作**，不要用取消再重新订阅的方式（会触发风控警报）。

## 七、常见问题 FAQ

**Q1：Claude Pro 支持年付吗？**
是。$200/年 = 约 $17/月，比月付省 15%。**但 Max 5x / Max 20x 没有年付**。

**Q2：Max 5x 与 Pro 用的模型一样吗？**
主力 Sonnet 4.6 一样。Max 层可优先接入 **Opus 系列**（Anthropic 的旗舰推理模型）与新特性 Beta。Pro 层的 Opus 访问在窗口内**极其有限**。

**Q3：Claude Code 需要单独付费吗？**
**不需要**。2026 年 3 月起，Claude Code 命令行工具已内置在 Pro / Max 订阅里。Pro $20 就能跑 Claude Code。

**Q4：能同时订阅 Pro 和 Max 吗？**
不能。**同一个账户同一时刻只能有一个订阅档位**。升档从 Pro 到 Max 5x 是即时生效、按比例结算差额。

**Q5：Claude Team 值不值得开？**
5 人以上的团队 + 需要独立数据管控 = 值得。**Team 会关闭"用你数据训练模型"这一默认设置**，且提供 SAML SSO 与集中账单。个人用户不需要。

**Q6：Max 20x 的 900 条 / 5 小时是硬上限吗？**
**这是社区测试估算**，官方不公开硬数字。真实体感取决于 prompt 长度、是否触发工具调用与 Extended Thinking。跑 Agent 长循环时，Max 20x 依然能撞限，只是概率远低于 Pro。

**Q7：Anthropic 会不会像 OpenAI 一样封 VPN？**
Anthropic 目前不对"使用 VPN 访问"做主动封禁，但会封"支付时 IP 与卡属地不符"。**上号可以用 VPN，付款瞬间必须回到卡属地 IP**。
