## 二、Pro 值不值得升 Max？三条判断线 📌

Max 比 Pro 贵 **10 倍**，绝大多数人不需要。判定线只有三条，命中任意一条再考虑：

### 判定线 A：你每天用 Comet 浏览器 > 2 小时

Comet 是 Perplexity 自研的 Agent 浏览器（Chromium 内核 + 内置 Agent）。Pro 的 Comet Agent 有**每日操作步数限制**（约 200-400 步/日），Max 是不限量 + 优先执行。

- Pro 用户表现：日常查资料、简单填表、订机票不卡额度
- Max 用户表现：让 Agent 每天跑数据抓取、竞品监控、批量比价才回本

### 判定线 B：你是重度 Deep Research 用户

Deep Research 单次会调用 30-100 次搜索 + 5-15 次模型推理，Pro 的额度是**每日 5 次 Deep Research**，Max 是**不限量 + 优先算力**。

- 咨询顾问 / 分析师日跑 10+ 次 → Max 回本
- 普通研究者周跑 3-5 次 → Pro 够

### 判定线 C：你必须最先用到新模型

Max 用户能提前 **2-6 周**用到 GPT / Claude / Gemini 新版本，Pro 用户平均滞后 4 周。仅适用于评测博主 / 关注前沿的研究者。

三条都不命中 → 老实用 Pro $20。

### 决策矩阵

| 使用场景 | Pro $20 | Max $200 |
|---|---|---|
| 个人搜索 / 写作 / 学习 | ✅✅✅ | ❌ 过剩 |
| Deep Research 周 10+ 次 | ⚠️ 卡额度 | ✅✅ |
| Comet Agent 全职跑数据抓取 | ⚠️ 步数不够 | ✅✅ |
| API 集成到自家产品 | ❌ 走 Sonar API | ❌ 同上 |
| 5-20 人研究团队 | ❌ | ⚠️ 不如 Enterprise |

## 三、国内 / NRA 用户订阅 Perplexity 的 6 条付款路径 💳

Perplexity 走 Stripe 收单，与 ChatGPT / Cursor 的风控逻辑接近但**略更严**——2026 年 3 月起，虚拟卡通过率明显下降。以下是 YoTrade 实测的六条路径（数据来源：2026 年 4-6 月 100+ 单 Perplexity 代付订单）：

### 路径 1：美卡（含 NRA 申请的 Chase / AmEx / Capital One）

✅ **首选**。Perplexity 的 Stripe 风控对美国 BIN 卡最友好，续订成功率接近 100%，无需 3DS。

- 优势：稳定、可开发票、地址匹配即可
- 劣势：NRA 申卡需要 [ITIN + LLC + Mercury](/blog/nra-us-credit-card-12-month-roadmap)，前置门槛高
- 适合：已经有美卡 或 已经在跑 NRA 路径的用户

⚠️ **地址匹配**：Perplexity 结算页要求 billing address 与卡片账单地址完全一致。如果卡片账单地址是 Mercury 的 Wyoming 虚拟地址，Perplexity billing 也填这个，别乱写。

### 路径 2：港卡（渣打 Mox / ZA Bank / HSBC 等）

✅ **成功率高，稳定性略低于美卡**。港卡走 Visa / Mastercard 国际线路，Perplexity 接受度良好。

- 优势：香港身份即可，无需 ITIN / LLC；月度 3DS 短信/APP 认证一次
- 劣势：初次订阅可能被 Stripe 触发 **CVV 二次验证**；连续 3 个月同卡续订后可能触发风控降档
- 适合：有港卡但不想搞美国身份的用户

📌 港卡怎么办？看 [香港银行卡办理完全指南](/blog/hk-bank-card-guide)。

### 路径 3：虚拟卡（Wise Multi-Currency / Nebeus / dLocal 等）

⚠️ **2026 年通过率骤降**。以下是 YoTrade 实测数据：

| 虚拟卡品牌 | 2025 Q4 通过率 | 2026 Q2 通过率 | 3 个月续订稳定性 |
|---|---|---|---|
| Wise Multi-Currency | 92% | 68% | 60%（可能中途被冻） |
| Nebeus USD Virtual | 85% | 45% | 40% |
| WildCard | 80% | 30% | 20% |
| 其他"9.9/月订阅"型虚拟卡 | 60% | < 10% | < 5% |

- 优势：无需海外身份，注册即用
- 劣势：**不稳定**、可能中途被扣款失败导致订阅降级、无法开正式发票
- 适合：短期尝鲜（1-2 个月内），或作为 Pro Trial 的过渡方案

❌ **不推荐**用虚拟卡做 Perplexity 年付——支付方一旦被封，Perplexity 会自动降到 Free，年付款项**难以退款**。

### 路径 4：Apple ID 内购（iOS 端 In-App Purchase）

⚠️ **Perplexity 2026 年 iOS 端支持 In-App Purchase 订阅 Pro**，但**只支持 Pro 月付**（$21.99，含 Apple 抽成），**不支持年付/Max/Enterprise**。

- 优势：Apple ID 换美区即可，无需信用卡（可用 Apple Gift Card 充值）

## 五、订阅完整流程：以美卡 / 港卡为例

### Step 1：注册账号

- 打开 `perplexity.ai`，用 Google / Apple / 邮箱注册
- 国内 IP 可直接注册，Perplexity 未对中国大陆 IP 做注册屏蔽（**但订阅结算页需要海外 IP**）

### Step 2：切海外 IP + 打开订阅页

- 到 `perplexity.ai/pro` 或 `settings/subscription`
- 挂海外节点（美国 / 香港 / 日本均可，稳定的家宽或商用节点最佳；机场共享 IP 高概率被 Stripe 拦截）

### Step 3：选 Pro / Max + 输入卡片

- 卡号 / 有效期 / CVV / **账单地址**（务必填卡片账单地址）
- 触发 3DS 短信/APP 认证 → 通过 → 完成订阅

### Step 4：验证订阅生效

- 回到 `perplexity.ai/settings/account`，看 subscription status 是 **Pro / Max**
- 首次订阅后建议**不要马上退 24h 内的钱**——Stripe 会记账号"退款率"，影响后续续订评分

### Step 5：绑定 Comet 浏览器（推荐）

- 到 `perplexity.ai/comet` 下载 Comet 浏览器（Mac / Windows）
- 登录同一 Perplexity 账号 → Comet Agent 自动同步订阅权限

## 六、常见问题 FAQ 💡

### Q1：Perplexity Pro 能取代 ChatGPT Plus 吗？

**取决于用途**。Perplexity 的核心优势是**实时搜索 + 引用溯源**，写作 / 编码不如 ChatGPT。研究、分析、时事类问题 Perplexity Pro 明显强；创意写作、复杂编码用 [ChatGPT](/blog/chatgpt-overseas-subscription-2026-guide) 或 [Cursor](/blog/cursor-pro-overseas-subscription-2026-guide) 更合适。

### Q2：Pro 用户能用几个设备？

官方 ToS 未硬性限制设备数，**但绑定设备指纹**——同账号在 3 个以上不同设备/IP 频繁切换会触发风控降到 Free。建议家 + 办公 + 手机三设备内。

### Q3：年付订阅中途取消能退款吗？

Perplexity Help Center 明确写：**年付订阅可在 24 小时内退款，超过 24 小时不退**。所以年付前先月付试用 1 个月再决定。

### Q4：Comet 浏览器需要单独付费吗？

不需要。**Pro / Max / Enterprise 用户免费用 Comet**，Free 用户下载 Comet 后仅能使用 Free 档权限。

### Q5：企业能不能用 Perplexity 训练自己的模型？

Enterprise Pro **默认关闭数据用于训练**（Free / Pro 也有 opt-out 开关，settings/privacy）。但如果要合规审计凭证，走 Enterprise Pro 才有 **SOC 2 Type II 报告 + DPA 协议**。
