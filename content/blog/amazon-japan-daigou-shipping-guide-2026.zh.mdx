## 一、日亚 vs 美亚：选品逻辑完全不一样

很多老海淘党第一次开日亚就懵了——首页全是日文、配送选项多到眼花、商品分类逻辑跟美亚完全不同。先建立一个判断框架：

| 维度 | 美亚 Amazon.com | 日亚 Amazon.co.jp |
|---|---|---|
| **核心品类优势** | 保健品 / 母婴 / 大件电子 / 书籍 | 药妆 / 限量周边 / 文具 / 日版游戏 / 日本独家食品 |
| **直邮中国比例** | 约 30% SKU 支持 Amazon Global | 约 15-20% SKU 支持（更受限） |
| **是否需要转运** | 大部分情况需要 | **几乎所有情况都需要** |
| **支付难度** | 国内双币卡通过率约 60% | 国内双币卡通过率更低，常被风控 |
| **退税机制** | 部分州免销售税 | 出境可免 10% 消费税（关键优势）✅ |
| **语言** | 英文 | 日文（Chrome 翻译可勉强用） |
| **平均代购时效（含转运）** | 7-15 天 | 5-12 天（日本到华距离更近）⚡ |

💡 **YoTrade 实战观察**：在 2024-2026 年所有日本线代购订单中，**药妆 + 二次元周边 + 文具**占比超过 75%。家电和大件电子虽然在日本也便宜，但**日本电压 100V / 国行 220V 不兼容**这个硬伤直接劝退大部分用户。

⚠️ **真话提醒**：日亚商品页价格 **默认含 10% 消费税**。如果你走 Tenso / Buyee 转运 + 出境，理论上可以申请退这 10%，但**普通商品在 Amazon 上"不退税"**——只有走免税专用渠道才能享受。这是日亚海淘最大的"信息差陷阱"，下面会展开说。

## 二、日亚下单的三种路径：直邮 vs 转运 vs 代购

### 2.1 三种路径的本质区别

| 路径 | 谁下单 | 谁收货 | 谁报关 | 适合场景 |
|---|---|---|---|---|
| **直邮 Amazon Global** | 你自己 | 你 | Amazon + 你 | 紧急 / 单价低 / Amazon Global 支持的 SKU |
| **转运（Tenso / Buyee 仓库）** | 你自己 | 转运公司日本仓 → 你 | 转运公司协助 | 长期高频 / 需要合单省运费 |
| **代购全包** | 代购方 | 代购仓库 → 你 | 代购方 | 一次性 / 不想折腾日文与日卡 / 怕清关 |

📌 **结论**：90% 的偶发性日本购物，**代购全包**就最省心。你不需要为了买一支 SK-II 神仙水去注册 Tenso + 办日本卡 + 学报关——除非你打算一个月买好几次，那转运账号才值得养。

### 2.2 直邮 Amazon Global 的真实可用度

Amazon Global 是日亚"国际配送"功能的官方名称。看上去很美好（一键直邮中国），但实际限制比美亚严：

- ⚠️ **大量 SKU 不参与**：药妆（含液体 / 膏状）、电池类（含锂电池数码相机）、食品几乎都被排除
- ⚠️ **运费基本是商品价的 50-100%**：买 5000 日元的东西，运费经常报 4000+ 日元
- ⚠️ **关税预付制**：Amazon 会在下单时**预估并预扣关税**，多退少补，但实际清关时如果被海关额外征税，差额你认
- ✅ 优点：清关失败 Amazon 全额退款，对完全的新手最友好

📌 **真实结论**：Amazon Global 适合"我买一本日文原版书 / 一个小手办，价值 < 3000 日元，不想折腾"的极简场景。**药妆党 / 二次元党 / 玩家几乎用不上**。

### 2.3 Tenso / Buyee 横评

这两家其实是同一家公司（BEENOS）旗下的两个产品线，定位不同：

| 维度 | Tenso（转运） | Buyee（代购） |
|---|---|---|
| **核心模式** | 给你一个日本地址，你自己下单 | 你给链接，他们替你下单+收货+寄给你 |
| **是否需要日本支付方式** | 是（必须有能在日亚成功扣款的卡） | 否（用国际信用卡 / PayPal 付给 Buyee 即可）✅ |
| **会员费** | 免费注册，按件收手续费 | 免费注册，按件收手续费 + 服务费 |
| **支持平台** | 仅 Tenso 仓库收货（你需要在 Amazon、Yahoo 拍卖等自己下单） | 日亚、乐天、Yahoo 拍卖、Mercari、官方品牌站 |
| **合单（合并多个包裹）** | 支持，按重量合算运费 | 支持 |
| **手续费水平** | 单件几百日元起 + 实际运费 | 单件几百日元起 + 商品价的小比例服务费 + 运费 |
| **适合人群** | 有日卡 / 有日本朋友卡 / 会日文 | 0 日文 / 0 日卡 / 怕风控 |

💡 **YoTrade 选择建议**：

- 长期高频日亚 + 有港卡 / Visa 能在日亚刷过卡 → **Tenso**（成本最低）
- 只是偶尔买几次 / 不想折腾支付 → **Buyee** 或直接找代购
- 抢限量手办 / 抽签商品（如 Bandai Premium 会员专属） → 走**代购**，他们有日本居民身份能参与抽签 🎯

## 五、消费税退税与中国海关清关：两个最容易翻车的点

### 5.1 日本 10% 消费税到底能不能退？

日亚商品页价格默认**含 10% 消费税**。出境理论上可申请退税，但有重要限制：

| 退税方式 | 适用条件 | 实操难度 |
|---|---|---|
| **机场退税（免税店 / Tax-Free Shop）** | 仅限你**本人在日本以游客身份**购买，护照 + 短期签证 | 不适用海淘 ❌ |
| **Buyee 等专业代购的免税服务** | 部分代购对支持的店铺自动免税开票 | ⭐⭐⭐（看代购家的接入度） |
| **Amazon 直邮国际订单** | Amazon Global 部分订单**会自动扣除消费税**显示 | ⭐⭐（取决于 SKU） |
| **Tenso 转运** | 由你自己在 Amazon 下单，**消费税通常不退** | ❌ |

💡 **实战建议**：算总成本时，**默认 10% 消费税退不回来**。如果代购方明确写"含免税服务"才可以减去这 10%。

### 5.2 中国海关清关：行邮税 vs 跨境电商综合税

货物从日本入境中国，可能走两种征税逻辑：

| 通道 | 适用 | 税率（2024-2026 政策） |
|---|---|---|
| **个人物品行邮税** | 个人自用 / 小批量 / 普通快递入境 | 食品保健品 13%、纺织品 / 数码 13%、化妆品 50%（高档香水 / 高档化妆品） |
| **跨境电商综合税** | 通过保税仓 / 综试区 / 海外仓的电商平台 | 进口环节增值税 + 消费税按 70% 征收 |

⚠️ **关键避坑点**：

1. **单件物品价值 + 运费 + 保险超过 800 元，超出部分要全额征税**
2. **化妆品类的"完税价格表"是海关编的固定值**，不是你的实际买价——一瓶 SK-II 神仙水即便你 1200 元买的，海关可能按 1800 元完税价 × 50% 行邮税征税
3. **手办 / 玩具的完税价格表通常比较友好**，单件大多在百元税额左右
4. 跨境电商单笔不超过 5000 元、年度不超过 26000 元的额度内，**走综合税通常比行邮税更划算**

📌 **新手最容易问的问题**：货被海关扣了怎么办？答：**正规代购全包路线，被扣的清关风险由代购承担**；自己转运被扣，要么补税要么退运，损失较大。这也是为什么我们建议偶发性购物直接走代购。
