## 2026 年 Copilot 全套套餐拆解

Copilot 目前分四档个人版（Free / Pro / Pro+ / Max）和两档团队版（Business / Enterprise）。**2026 年 6 月 1 日**是关键分水岭：GitHub 把计费单位从"数请求次数"的 Premium Request Units（PRU）**切换成按 token 实际消耗计算的 GitHub AI Credits**，agent mode、chat、代码审查都从这个每月刷新的额度池里扣。

### 价格 + 额度一览

| 套餐 | 月费 | 代码补全 | AI Credits / 月 | 适用场景 |
|---|---|---|---|---|
| **Free** | $0 | ✅ 限量 | 少量试用额度 | 体验、轻度使用 |
| **Pro** | $10 | ✅ 不限量 | 标准额度 | 日常主力开发 |
| **Pro+** | $39 | ✅ 不限量 | **约 3 倍标准额度** | 高频 agent mode / 大量调用付费模型 |
| **Max** | $100 | ✅ 不限量 | **约 10 倍标准额度** + 新功能优先体验 | 全职 AI 编程重度用户 |
| **Business** | $19/座 | ✅ 不限量 | 团队池化额度 | 5-50 人团队，统一开票 + 权限管控 |
| **Enterprise** | $39/座 | ✅ 不限量 | 池化额度 + 自定义策略 | 大型组织，需 SCIM / 审计日志 |

📌 **没有年付折扣这回事**——Copilot 目前只有月付一种周期，不像 Cursor 那样年付打 8 折，所以不用纠结"要不要锁年付"，按月订就行，用不满意随时降级或取消。

⚠️ **AI Credits 计费变更要注意什么**：2026 年 6 月起，月付用户已经全部迁移到新计费方式；这意味着"同样 $10，能跑多少次对话"取决于你调用的模型和上下文长度——用 Claude Sonnet 这类主力模型做一次完整对话消耗的 credit，比只做代码补全高不少。✅ **推荐做法**：迁移后头一周留意一下自己的额度消耗速度，官方后台（github.com/settings/billing）能看到实时用量，发现经常在月中就烧光再考虑升档，不要一上来就订最贵的 Max。

## Chat / Agent Mode 里能调用哪些模型

Copilot 早就不是"只会代码补全"的工具了。付费档位的 chat 和 agent mode 里，可以在多家模型间自由切换，这也是它和 Cursor、Claude Code 竞争的核心卖点：

| 模型系列 | 适合场景 | 相对 Credit 消耗 |
|---|---|---|
| **Claude Sonnet / Opus 系列** | 复杂重构、长上下文理解 | 中 - 高 |
| **GPT 系列（OpenAI）** | 通用问答、快速生成 | 中 |
| **Gemini 系列（Google）** | 多模态、长文档分析 | 中 |
| **Copilot 自研模型** | 纯代码补全（Tab） | 不计入 AI Credits |

💡 **YoTrade 实战观察**：日常代码补全完全免费不计额度，只有主动唤起 chat 或 agent mode 让模型"思考"和"生成"时才会扣 AI Credits。习惯把 Tab 补全当主力、偶尔用 chat 问问题的开发者，Pro $10 的额度基本用不完；习惯让 agent mode 自动跑完整个任务（写代码 + 跑测试 + 改 bug）的重度用户，额度消耗速度会快很多，这也是 Pro+ 和 Max 存在的意义。

⚠️ **风险点**：不同模型的 Credit 消耗比例官方没有公开固定汇率，且会随后台调价调整，**不要按老经验估算额度够不够用**，直接看 github.com/settings/billing 里的实时用量最准。

## Copilot Student：免费计划现在还能申请吗

在读学生是薅 Copilot 最划算的路径，但 2026 年这条路走得不太平：

| 时间 | 事件 |
|---|---|
| 2026 年 3 月 12 日 | GitHub 把学生福利从"直接送 Copilot Pro 席位"改成独立的 **Copilot Student 计划**，功能介于 Free 和 Pro 之间 |
| 2026 年 4 月 | 因 agent 类工作负载算力紧张，GitHub **暂停了 Student / Pro / Pro+ / Max 的新用户注册** |
| 2026 年 6 月 17 日 | 官方宣布**分批逐步重新开放**注册，新用户名额陆续放出 |

💡 **YoTrade 实战观察**：截至 8 月，Student 计划注册已经基本恢复，但仍可能出现"审核通过却看到额度不对"的情况（社区讨论里不少人反馈过），遇到这种建议直接去 GitHub Support 提工单，而不是等它自己恢复。

✅ **申请方式**：走 GitHub Education 的 Student Developer Pack，最快路径是用学校邮箱（`.edu` 或学校域名）直接验证；没有教育邮箱的，上传带日期的学生证或在读证明也能过审。验证通过后进 github.com/education 开通即可，不需要绑卡。

### ① 美卡（LLC 名下）——最推荐路径

如果你已经有美国 LLC + Mercury / Relay 账户 + 美卡（比如 Amex Blue Business Plus 或 Chase Ink），这是**零溢价、通过率最高**的方案：

## ❓ 常见问题

**Q：我现在用的是 Free 档，什么时候该升级到 Pro？**

A：当你发现自己每天都在主动打开 chat 窗口问问题、或者频繁被提示"本月额度已用完"，就是升级信号。如果只是偶尔用用代码补全，Free 完全够用，不用着急花钱。

**Q：Business 和 Enterprise 到底怎么选？**

A：核心区别在合规和管控深度。团队规模不大、只需要统一计费和基本权限管理，Business $19/座 够用；如果公司有 SSO/SCIM 强制要求、需要审计日志和自定义使用策略，才需要上 Enterprise $39/座。大多数 5-50 人的创业团队订 Business 就足够。

**Q：没有信用卡，只能用代刷吗？**

A：不是唯一选项，但确实是最省心的一条。前提是你能拿到一张能通过国际交易验证的卡（美卡、港卡、或开通了境外消费权限的国内双币卡）都可以自己订；如果暂时都没有，找实名独立号代刷是最快落地的路径，不用先花时间办卡再订阅。

**Q：AI Credits 用完了会怎样？**

A：官方设计是超额后可以选择按量付费购买额外 Credits，或者等下个月额度刷新前先降级使用免费的代码补全功能。不会直接停用账户，但 chat / agent mode 会被限制，直到额度恢复或手动加购。
